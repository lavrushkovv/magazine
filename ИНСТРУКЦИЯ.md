# 🚀 Инструкция по публикации TechStore в Telegram
## Хостинг: Render.com — абсолютно бесплатно, без карты, навсегда

## ⚠️ ПЕРВЫМ ДЕЛОМ — сбросьте токен бота!
1. Откройте @BotFather в Telegram
2. Напишите /mybots → выберите вашего бота
3. Нажмите "Revoke current token" → подтвердите
4. Скопируйте НОВЫЙ токен — он понадобится в шаге 4

## Почему Render, а не Railway?

Render даёт бесплатный тариф навсегда, без кредитной карты при регистрации.
Единственная особенность: если к серверу никто не обращается 15 минут, он
"засыпает", и следующий запрос грузится на 20-30 секунд дольше. Эту проблему
полностью решает бесплатный сервис UptimeRobot (шаг 6) — он будет
"подталкивать" ваш сервер каждые 5 минут, и он не будет засыпать.

## Шаг 1 — Зарегистрируйтесь на GitHub (бесплатно)
1. Зайдите на https://github.com/signup
2. Введите email, пароль, username
3. Подтвердите email

---

## Шаг 2 — Загрузите файлы магазина на GitHub
1. Зайдите на https://github.com/new
2. Название репозитория: techstore
3. Выберите "Public" → "Create repository"
4. Нажмите "uploading an existing file"
5. Загрузите ВСЕ файлы:
   - index.html
   - server.py
   - requirements.txt
   - render.yaml
   - data/products.csv (создайте папку data и положите файл туда)
6. Нажмите "Commit changes"

---

## Шаг 3 — Регистрация на Render (бесплатно, без карты)
1. Зайдите на https://render.com
2. Нажмите "Get Started" → "Sign up with GitHub"
3. Разрешите доступ к вашим репозиториям
4. Карта НЕ требуется

---

## Шаг 4 — Деплой сервера
1. В панели Render нажмите "New +" → "Web Service"
2. Выберите ваш репозиторий techstore → "Connect"
3. Render найдёт файл render.yaml и сам всё настроит. Если не нашёл —
   заполните вручную:
   - Name: techstore-backend
   - Runtime: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn server:app --bind 0.0.0.0:$PORT
   - Instance Type: Free
4. Нажмите "Create Web Service"
5. Дождитесь надписи "Live" (зелёный кружок) — это займёт 2-5 минут

---

## Шаг 5 — Заполните переменные окружения
1. В панели вашего сервиса откройте вкладку "Environment"
2. Нажмите "Add Environment Variable" и добавьте по одной:

   BOT_TOKEN    = ваш_новый_токен_бота
   ADMIN_ID     = 1398884
   ADMIN_SECRET = придумайте_свой_ключ_например_Xyz123!
   SHOP_URL     = (заполните после получения URL ниже)

3. Скопируйте URL вашего сервиса сверху страницы, он выглядит так:
   https://techstore-backend-xxxx.onrender.com
4. Вернитесь в Environment → впишите этот URL в переменную SHOP_URL
5. Нажмите "Save Changes" — сервис перезапустится автоматически

---

## Шаг 6 — Подключите UptimeRobot, чтобы сервер не засыпал
1. Зайдите на https://uptimerobot.com → зарегистрируйтесь бесплатно
2. Нажмите "Add New Monitor"
3. Заполните:
   - Monitor Type: HTTP(s)
   - Friendly Name: TechStore
   - URL: https://ваш-сервис.onrender.com/ping
   - Monitoring Interval: 5 minutes
4. Нажмите "Create Monitor"

Готово — теперь UptimeRobot будет заходить на ваш сервер каждые 5 минут,
и он никогда не будет засыпать.

---

## Шаг 7 — Вставьте URL сервера в index.html
1. Откройте index.html на GitHub (или на компьютере)
2. Найдите строку:
   BACKEND_URL: 'https://YOUR-APP.onrender.com'
3. Замените на ваш реальный URL из шага 5:
   BACKEND_URL: 'https://techstore-backend-xxxx.onrender.com'
4. Сохраните изменения (Commit changes на GitHub)

---

## Шаг 10 — Проверка
1. Откройте бота в Telegram → нажмите кнопку меню

## 📋 Как обновлять цены каждый день

### Через GitHub (самый простой способ):
1. Откройте data/products.csv в репозитории на GitHub
2. Нажмите карандаш (Edit this file)
3. Измените цены в колонке price
4. Нажмите "Commit changes"
5. Render автоматически подхватит изменения при следующем деплое

ВАЖНО: после изменения файла на GitHub нужно зайти в панель Render →
ваш сервис → "Manual Deploy" → "Deploy latest commit", чтобы сервер
обновил данные.

### Через компьютер (для уверенных пользователей):
1. Откройте products.csv в Excel или Google Таблицах
2. Измените цены → сохраните как CSV
3. Загрузите командой в терминале:

curl -X POST https://ваш-сервис.onrender.com/api/products/upload-csv \
     -H "X-Admin-Token: ваш_секретный_ключ" \
     -F "file=@products.csv"

4. Вы получите уведомление в Telegram: "✅ Каталог обновлён!"

## 🔄 Смена статуса заказа

curl -X PATCH https://ваш-сервис.onrender.com/api/orders/НОМЕР_ЗАКАЗА/status \
     -H "X-Admin-Token: ваш_секретный_ключ" \
     -H "Content-Type: application/json" \
     -d '{"status":"processing"}'

Статусы:
- new        = Новый (ставится автоматически)
- processing = Обрабатывается
- ready      = Готов к выдаче / В пути
- done       = Выдан

При смене статуса покупателю автоматически приходит уведомление в Telegram!

## ❓ Частые вопросы

Q: Магазин долго открывается первый раз
A: Это нормально для бесплатного тарифа Render — сервер "проснулся" после
   простоя. После настройки UptimeRobot (шаг 6) это будет случаться редко.

Q: Магазин не открывается совсем
A: Проверьте что в BotFather указан правильный URL с GitHub Pages, и что
   в index.html указан правильный BACKEND_URL.

Q: Уведомления о заказах не приходят
A: Проверьте переменные BOT_TOKEN и ADMIN_ID в Environment на Render.

Q: Цены не обновились после загрузки CSV
A: Зайдите в панель Render → Manual Deploy → Deploy latest commit.

Q: Как добавить фото товаров?
A: 1) Зарегистрируйтесь на cloudinary.com (бесплатно)
   2) Загрузите фото → скопируйте URL
   3) Вставьте URL в колонку image в products.csv
